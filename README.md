# NIST CSF v1.1 Cybersecurity Gap Analysis & Audit Portfolio

This repository contains a comprehensive, simulated Cybersecurity Gap Analysis based on the **NIST Cybersecurity Framework (CSF) v1.1**. 
The project demonstrates the practical application of Governance, Risk, and Compliance (GRC) principles within a highly regulated corporate environment.

## 📌 Project Overview
The analysis evaluates the security posture and maturity level of a mid-sized bio-pharmaceutical organization handling critical intellectual property, proprietary medical research, and hybrid cloud/on-premise infrastructure. 

The evaluation systematically reviews organizational controls across the core NIST CSF functions, bridging the gap between technical operations and business-driven risk management.

## 🗂️ Portfolio Structure & Deliverables
The framework architecture and high-level project presentation are maintained in English. 
Detailed technical audit notes, technical findings, and gap analysis details are documented in **Italian**, reflecting a business case tailored for localized compliance and regulatory standards.

* 📄 **IDENTIFY (ID)** - *Coming Soon* (Asset Management, Risk Assessment, Governance)
* 📄 **PROTECT (PR)** - *Coming Soon* (Access Control, Data Security, Patching & Maintenance)
* 📄 **DETECT (DE)** - *In Progress* (Anomalies & Events, Security Continuous Monitoring)
* 📄 **RESPOND (RS)** - *Upcoming* (Incident Response Planning & Communications)
* 📄 **RECOVER (RC)** - *Upcoming* (Disaster Recovery & Lessons Learned)

## 🎯 Key Skills Demonstrated
* **Framework Mapping:** Practical alignment of corporate infrastructure with NIST CSF v1.1 and ISC² CC domains.
* **Risk Auditing & Governance:** Translating raw technical evidence (IAM, Network, Cloud configurations) into compliance outcomes (PASS/FAIL) and strategic risk impacts.
* **Executive Advisory:** Formulating professional, non-colloquial remediation notes tailored for C-level executives and technical stakeholders.
