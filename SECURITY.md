# Security Policy

## Reporting Vulnerabilities
Trattandosi di un repository di portfolio personale dedicato a casi studio di Governance, Risk, and Compliance (GRC), il contenuto ha scopo puramente dimostrativo.

Se dovessi riscontrare errori, imprecisioni tecniche o problemi relativi alla protezione dei dati in questo repository, ti invito ad aprire una **GitHub Issue** o a contattarmi direttamente su LinkedIn.
